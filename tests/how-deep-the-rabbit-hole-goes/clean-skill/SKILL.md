# commit-message

## Кроки

1. Подивись `git status` і `git diff --staged` (якщо порожньо — `git diff`).
2. Згрупуй зміни за змістом, а не за файлами.
3. Напиши заголовок до 72 символів у наказовому способі й короткий опис «чому».

## Правила

- Нічого не комітиш сам — лише пропонуєш текст.
- Не вигадуй змін, яких немає в diff.
