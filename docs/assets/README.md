# README illustrations

Original AI-generated illustrations inspired by Lewis Carroll's *Alice's Adventures in Wonderland*.
Both the [English README](../../README.md) and [Ukrainian README](../../README.uk.md) use the same
image files, with localized alt text and captions.

Generated on 2026-11-16 with the built-in `image_gen` tool, then edited to add the owner-supplied
“БЕЗ ДУШІ / WITHOUT SOUL” logo in the lower-right corner. The logo's exterior white background was
removed; its white ghost, black lettering and red brushstroke were retained.

## Generation prompts

These are the exact prompts used for the two base illustrations, before the logo edits described
above. A new generation may produce different artwork.

### Rabbit-hole cover

```text
Use case: illustration-story
Asset type: wide hero illustration for the GitHub README of instinct, a tool for reviewing agent skills before installation.
Primary request: an original Alice in Wonderland illustration inspired by Lewis Carroll's public-domain story. Alice and the White Rabbit pause at the edge of a deep rabbit hole before entering; curiosity tempered by careful observation, a visual metaphor for inspecting unfamiliar software before trusting it.
Scene/backdrop: an enchanted woodland, twisting tree roots around a deep, warmly lit rabbit hole, a few playing cards descending into the dark.
Subjects: Victorian Alice with long loose brown hair, a simple muted blue-gray dress and cream pinafore; an expressive White Rabbit in a waistcoat holding a pocket watch. Their poses clearly face the opening.
Style/medium: detailed Victorian pen-and-ink book illustration with restrained watercolor washes on warm ivory paper; elegant etched lines, storybook atmosphere, original character designs.
Composition/framing: panoramic horizontal composition, approximately 2:1 aspect ratio, crisp readable silhouettes at README width, generous breathing room around the scene.
Lighting/mood: mysterious and inviting, warm light within the hole contrasting with subdued woodland shadows.
Constraints: no text, lettering, labels, logos, watermark, border, UI, modern devices, neon cyberpunk, or Disney character designs. The scene must feel like a coherent classic book illustration.
```

### Reading the fine print

```text
Use case: illustration-story
Asset type: supporting horizontal illustration for the How it works section of the instinct security-audit README.
Primary request: an original Alice in Wonderland scene about reading the fine print before trusting an invitation, inspired by Lewis Carroll's public-domain story.
Scene/backdrop: a small wooden table in a curious woodland clearing beside a miniature closed door. Several playing cards and an unrolled parchment rest on the table.
Subjects: Victorian Alice with long loose brown hair, a simple muted blue-gray dress and cream pinafore, carefully examining the parchment through a magnifying glass while the White Rabbit in a waistcoat waits beside her with his pocket watch. Show Alice actively inspecting the paper, with readable body language and natural hands.
Style/medium: detailed Victorian pen-and-ink book illustration with restrained watercolor washes on warm ivory paper; elegant etched lines and original character designs. Closely match a classic illustrated-book scene, suitable as a companion to a woodland rabbit-hole hero.
Composition/framing: wide horizontal composition, approximately 2:1 aspect ratio, one cohesive scene, uncluttered focal point on inspection, sharp at README width.
Lighting/mood: thoughtful and quietly whimsical, warm diffuse light with delicate woodland shadows.
Constraints: the paper has abstract ink strokes rather than legible words; no actual text, labels, logos, watermark, border, UI, modern devices, neon cyberpunk, or Disney character designs. No claim of guaranteed security.
```
